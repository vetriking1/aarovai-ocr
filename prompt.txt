TOTAL ACTUAL ROW (totalActualKg):
- Use ONLY the row labeled "Total Actual in Kgs." It has exactly 14 cells. Every cell counts, including each "0" and "0.00". Never skip, merge or reorder cells
- Do NOT use values from "Total Set Weight in Kgs.", "Variations in %.", "Recipe Targets" or any per-mix row. In the text layer the Set and Actual values can appear next to each other (e.g. "5.00 4.91"), so make sure you take the Actual one
- Map cells to keys by position:
  1 -> "20MM"
  2 -> "SAND"
  3 -> "SAND1" (even if the header reads "SAND 2")
  4 -> "12MM"
  5 -> ignore (unnamed)
  6 -> "CEMENT1"
  7 -> "CEMENT2"
  8 -> "FLYASH"
  9 -> ignore (unnamed)
  10 -> "WATER"
  11 -> "MS_ICE"

  14 -> "M_FIBER"
- COUNT FROM THE RIGHT to avoid shifting: the last cell is M.FIBER, the second-last is ADMIX2, the third-last is ADMIX1, the fourth-last is MS/ICE, and the fifth-last is WATER (a large number such as 818 or 825)

- ADMIX1 and ADMIX2 are not output separately. Only their sum appears as "ADMIX"
